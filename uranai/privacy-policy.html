プライバシーポリシー

命運ログ（iOS / Android） |  最終更新日: 2026年9月24日

株式会社バーニングトライブ（以下「当社」）は、アプリ「命運ログ」（以下「本アプリ」）における利用者の情報を、以下のとおり取り扱います。

1. 端末内に保存する情報

命運ログ（今日のテーマ、感謝・手放したいこと、気力・見通しなど）、鑑定や診断の結果、各種設定は、利用者の端末内にだけ保存します。当社のサーバーには送信しません。

2. AI鑑定で送信する情報（Premium・同意した場合のみ）

AIによる鑑定文の作成（四柱推命・手相・今日の運勢・タロット・AIへの相談）は Premium 会員向けの機能です。初めて使うときに、送信先と送る内容を画面で示して同意を確認します。同意しない場合は送信しません。

  • 送る内容: 機能ごとに、命式（干支）と五行バランス、選んだ手相の特徴、生年月日・星座・日付、引いたカードと質問、入力した悩み・相談の文章
  • 送信先: 当社が運用するサーバー（Cloudflare, Inc. の Cloudflare Workers）を経由して、Google LLC（米国）の Gemini API へ送り、回答を受け取ります。
  • Gemini API の利用条件により、送信した内容と生成された回答が Google のサービス改善に利用される場合があります。当社から即時の削除を保証することはできません。
  • 当社のサーバーは、送信内容を保存しません。障害調査のため、エラーの種類などの技術情報を記録することがあります。また、不正利用を防ぐため、IPアドレスを回数制限に一時的に使います。

氏名・住所・電話番号・メールアドレスなどの連絡先、他人の情報、病歴・信条などの要配慮個人情報は入力しないでください。同意は、本アプリの設定画面（ホーム右上の歯車）の「AIへの送信の同意を取り消す」からいつでも取り消せます。

3. 課金（サブスクリプション）

購入と購読状態の確認に、App Store / Google Play と RevenueCat, Inc. のサービスを使います。RevenueCat には、アプリが自動で作る匿名の利用者IDと購入履歴が送られます。氏名やカード情報を当社が受け取ることはありません。
RevenueCat のプライバシーポリシー: https://www.revenuecat.com/privacy/

4. 自社アプリの紹介（広告）

Premium でない利用者には、ヒントタブに当社の他のアプリを紹介する枠を表示します。第三者の広告SDKは使わず、広告識別子（IDFA / 広告ID）も取得しません。アプリをまたいだトラッキングは行いません。

  • 紹介する内容の一覧を、当社のサーバー（ads.burningtribe.tokyo）から取得します。このとき、アプリ名とOSの種類を送ります。取得は、購読状態が確認できた無料の利用者が、その枠のあるタブを表示しているときだけ行います。
  • 紹介枠をタップすると、当社の計測用URLを経由してストアのページなどを開きます。どの紹介がタップされたかを集計します。

5. データの削除

命運ログは各ログの削除ボタンから削除できます。アプリをアンインストールすると、端末内のすべてのデータが削除されます。AIへの送信の同意は設定画面から取り消せます。

6. 本アプリの位置づけ

本アプリはエンターテインメントおよび自己理解の補助を目的としています。占いやAIの結果を保証するものではなく、医療・法律・金融その他の専門的な助言に代わるものではありません。

7. 改定

本ポリシーを改定する場合は、このページで告知します。

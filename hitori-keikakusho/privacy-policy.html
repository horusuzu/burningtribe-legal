プライバシーポリシー

ひとり計画書  |  最終更新日: 2026年9月24日

株式会社バーニングトライブ（以下「当社」）は、iOS / Android アプリ「ひとり計画書」（以下「本アプリ」）における利用者情報の取り扱いを以下のとおり定めます。

1. 端末内に保存する情報

利用者が入力した計画（計画名・理想・方針・制約・重点テーマ・数値）、今週の打ち手と完了チェック、初回案内の完了日時、外部AI送信への同意状態は、端末内（アプリの保存領域）にのみ保存します。当社のサーバーへ同期・バックアップはしません。

2. オンラインAI計画レビュー（Premium・同意した場合のみ）

Premium 会員が「オンラインAIモード」をオンにし、送信内容を示す確認画面で同意した場合に限り、「AI計画レビュー」を押したときに次の情報を送信します。同意しない場合、無料版の場合は送信せず、端末内で点検します。

送信する情報: 表示中の計画の計画名・理想・方針・制約（入力した文章のまま、各240字まで）、重点テーマ、準備度、数値サマリー（月の目標値・不足件数・必要候補数）、直近の行動（最大5件）。合計最大1500字で、メールアドレス・電話番号・URL は自動で伏字化します。氏名・住所・取引先名・認証情報・機密情報は入力しないでください。

送信先: 当社が運営する Cloudflare Workers（ai-counseling.horusuzu.workers.dev）を経由して Google LLC の Gemini API へ送り、回答を受け取ります。Cloudflare Workers は不正利用防止（回数制限）のため通信元 IP アドレスを処理します。Google による処理は Google のプライバシーポリシーおよび Gemini API 利用規約に従います。

同意は、アプリの「設定」＞「外部AI送信への同意をリセット」またはホーム画面のオンラインAIモードをオフにすることで、いつでも取り消せます。

AI回答の報告: オンラインAIの回答を「この回答を報告する」で報告した場合に限り、アプリ識別子、重複防止用の報告ID、選んだ理由、送信した計画の要約、AIの回答を、Cloudflare Workers 経由で当社の報告受付先へ送信します。

3. 自社アプリの紹介表示（無料版）

無料版では、当社の他アプリの紹介を表示します。購読状態を確認でき、画面が表示中かつアプリが前面にあるときだけ、当社サーバー（ads.burningtribe.tokyo）から紹介内容を取得し、表示・タップの計測として本アプリの識別子・紹介先アプリ・OS 種別を送信します。広告識別子（IDFA / 広告ID）は取得せず、第三者の広告 SDK や広告目的のトラッキングは使用しません。Premium 会員には表示せず、通信もしません。

4. サブスクリプション

購入と購読状態の確認に RevenueCat, Inc. と App Store / Google Play の課金システムを使用します。RevenueCat には、匿名のアプリ利用者ID、購入履歴、端末・OS の情報が送信されます。当社はクレジットカード番号などの決済情報を取得しません。RevenueCat のプライバシーポリシー: https://www.revenuecat.com/privacy

5. 通知

無料トライアル付きプランを購入した場合、通知を許可されたときに限り、トライアル終了前のお知らせを端末内で予約します（ローカル通知）。通知内容を当社へ送信することはありません。

6. お問い合わせ・フィードバック

設定画面から、利用者自身のメールアプリまたは LINE でお問い合わせいただけます。お送りいただいた内容は、返信と改善のためにのみ使用します。

7. データの削除

端末内のデータは本アプリを削除（アンインストール）すると消去されます。本アプリ内に全データを一括削除する機能はありません。サブスクリプションの解約は、App Store / Google Play の購読管理から行えます。当社や RevenueCat が保持する情報の開示・削除のご依頼は、下記の窓口へご連絡ください。

8. 第三者提供

上記の委託先（Cloudflare, Inc.、Google LLC、RevenueCat, Inc.、Apple Inc.、Google LLC（Google Play））への送信を除き、法令に基づく場合を除いて、利用者の同意なく第三者へ提供しません。

プライバシーポリシー

VPNシャッフル  |  最終更新日: 2026年9月26日

1. このアプリが扱う情報

  • NordLynx の秘密鍵: ユーザーが入力した NordVPN のアクセストークンを使って Nord の API から取得し、端末内の安全な保管領域（iOS はキーチェーン、Android はアプリ専用領域）にだけ保存します。当社のサーバーへは送信しません。
  • アクセストークン: 秘密鍵の取得のためだけに Nord の API へ送信し、保存しません。
  • 設定: 切り替えの間隔、切り替え先の国、接続先の履歴（直近のサーバー名・回数）は端末内にだけ保存します。

当社はユーザーの通信内容、閲覧履歴、IPアドレス、位置情報を取得・保存しません。当社が運営するサーバーはこのアプリの動作に使われていません。

2. 通信先

  • NordVPN（Nord Security）: サーバー一覧の取得、秘密鍵の取得、および VPN 接続そのもの。VPN 接続中の通信は NordVPN のサーバーを経由します。取り扱いは Nord Security のプライバシーポリシーに従います: https://nordvpn.com/privacy-policy/
  • RevenueCat（サブスクリプションの状態確認）: https://www.revenuecat.com/privacy
  • Apple / Google（アプリ内課金）: https://www.apple.com/legal/privacy/ / https://policies.google.com/privacy

広告SDK・アクセス解析SDKは使用しません。

3. サブスクリプション

自動切り替え機能は Apple または Google のアプリ内課金によるサブスクリプションで提供します。購入処理と権利状態の確認に必要な購入情報と匿名のアプリ利用者識別子は、各ストアと RevenueCat で処理されます。当社はクレジットカード番号を取得しません。NordVPN の利用料金はこのサブスクリプションに含まれません。

4. 紹介リンク（PR）

アプリ内の「NordVPN を契約する」リンクは紹介リンクです。このリンクから契約された場合、運営者に紹介特典が付くことがあります。リンク先での情報の取り扱いは NordVPN の規定に従います。

5. データの削除

設定画面の「登録した鍵を削除」で、端末内の秘密鍵と VPN 構成を削除できます。アプリをアンインストールすると端末内のデータはすべて削除されます。購入履歴は各ストアのアカウントで管理されます。

6. 第三者との関係

本アプリは Nord Security とは提携・関係のない独立したアプリです。NordVPN は Nord Security の商標です。

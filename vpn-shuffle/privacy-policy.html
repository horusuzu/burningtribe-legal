1. このアプリが扱う情報

  • NordLynx の秘密鍵: ユーザーが入力した NordVPN のアクセストークンを使って Nord の API から取得し、端末内の安全な保管領域（iOS はキーチェーン、Android はアプリ専用領域）にだけ保存します。当社のサーバーへは送信しません。
  • アクセストークン: 秘密鍵の取得のためだけに Nord の API へ送信し、保存しません。
  • WireGuard 設定ファイル: 他の VPN 事業者や自分のサーバーから取得した .conf を取り込む場合、秘密鍵・公開鍵・接続先・DNS・ルーティング設定を接続と切り替えのために扱います。本文は端末内に保存し、iOS はキーチェーン（VPN 拡張と共有）、Android は画面用の安全な保管領域と VPN 制御用のアプリ専用領域に保持します。名前・接続先ホストなどの索引はアプリ内に保存します。当社のサーバーへ送信しません。
  • 設定: 切り替えの間隔、切り替え先の国、接続先の履歴（直近のサーバー名・回数）は端末内にだけ保存します。

VPN トンネルは通信を暗号化して選択した VPN 接続先へ転送するために端末上でパケットを処理します。当社はその通信内容・閲覧履歴・利用者の送信元 IP アドレスを収集するサーバーを運営しておらず、これらを収集・販売・広告利用しません。位置情報の権限は要求しません。接続状態、接続時刻、次回切り替え時刻、回数、エラーは端末内に保持します。接続先ホスト/IP やネットワーク状態を含む技術的な診断ログが OS の端末内ログに残る場合がありますが、アプリはそれを当社へ送信しません。

2. 通信先

  • NordVPN（Nord Security）: サーバー一覧の取得、秘密鍵の取得、および VPN 接続そのもの。VPN 接続中の通信は NordVPN のサーバーを経由します。取り扱いは Nord Security のプライバシーポリシーに従います: https://nordvpn.com/privacy-policy/
  • その他の VPN 事業者・自分の VPN サーバー: 取り込んだ設定に指定されたサーバーへ接続し、設定された DNS サーバーで名前解決を行います。通信はその接続先で処理されます。VPN 事業者には接続元 IP アドレスや転送先など、通信に必要な情報が伝わります。処理する国・保存場所・保存期間は選択した事業者とサーバーに依存し、当社では管理しません。利用前にその事業者のプライバシーポリシーを確認してください。
  • RevenueCat（サブスクリプションの状態確認）: https://www.revenuecat.com/privacy
  • Apple / Google（アプリ内課金）: https://www.apple.com/legal/privacy/ / https://policies.google.com/privacy

広告SDK・アクセス解析SDKは使用しません。

3. サブスクリプション

自動切り替え機能は Apple または Google のアプリ内課金によるサブスクリプションで提供します。購入処理と権利状態の確認・復元に必要な購入情報と匿名のアプリ利用者識別子、SDK の動作に必要なアプリ・端末情報は、各ストアと RevenueCat で処理されます。RevenueCat は顧客データを米国の AWS データセンターに保存すると公表しています。Apple / Google の購入情報は各社の管理するシステムに保存されます。これは VPN の通信内容を収集する機能ではなく、VPN の秘密鍵・設定ファイル・閲覧履歴を RevenueCat に送りません。当社はクレジットカード番号を取得しません。NordVPN の利用料金はこのサブスクリプションに含まれません。

4. 紹介リンク（PR）

アプリ内の「NordVPN を契約する」リンクは紹介リンクです。このリンクから契約された場合、運営者に紹介特典が付くことがあります。リンク先での情報の取り扱いは NordVPN の規定に従います。

5. データの削除

設定画面の「登録した鍵を削除」で、端末内の秘密鍵と VPN 構成を削除できます。WireGuard 設定は設定ファイルの一覧から削除できます。iOS のキーチェーンはアンインストール後も残る場合があるため、削除したい鍵や設定ファイルはアプリ内で削除してからアンインストールしてください。購入履歴は各ストアのアカウントで管理されます。

6. 第三者との関係

本アプリは Nord Security とは提携・関係のない独立したアプリです。NordVPN は Nord Security の商標です。

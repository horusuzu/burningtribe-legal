プライバシーポリシー

ひとり会議｜話すだけで悩みを整理
最終更新日: 2026年10月2日

1. 取得する情報

本アプリは、アカウント識別情報、相談内容、音声から変換されたテキスト、相談ノート、行動目標、振り返りと達成度、購入状態、アプリの動作に必要な技術情報を取り扱います。マイクは音声会話中だけ、利用者の許可を得て使用します。アカウントはメールアドレスや氏名の登録なしで作成でき、アプリ内に表示される引き継ぎコードで管理します。アカウント作成時は、乱用防止のため接続元IPアドレスを元に戻せない値（ハッシュ値）に変換して回数を数え、48時間以内に削除します。IPアドレスそのものは保存しません。

2. 利用目的

情報は、対話による悩みの整理、相談記録と続きの会話、購入状態の確認、不正利用防止、障害対応、サービス改善のために利用します。本アプリは医療、診断、緊急対応を目的としません。

3. 外部AIサービス（Google・OpenAI）への送信

送信先: 文字の相談（質問と整理カードの作成）はGoogle LLC（米国）のGemini API、音声での会話はOpenAI, L.L.C.（米国）のAPIです。
送信のタイミングと同意: 相談ごとに、アプリ内の確認画面で送信先と送信内容を表示し、利用者が同意した場合にだけ送信します。同意しない場合は送信せず、チケットも消費しません。

送信するデータ

  • 会話中のマイクの音声（ライブ音声の応答のため。OpenAIへ送信）
  • 利用者が入力した文字、または音声の文字起こし（Googleへ送信。音声での会話中はOpenAIにも送信）
  • その相談の質問と回答（Googleへ送信。音声での会話中はOpenAIにも送信）
  • 「続きを話す」を選んだ場合は、前回の相談ノートの整理結果・行動・振り返り・達成度（Googleへ送信。音声での会話中はOpenAIにも送信）

取得の方法: 音声は会話中だけマイクから（OSの許可を得て）取得し、文字は利用者の入力または音声の文字起こしで取得します。
利用目的: 質問の生成、音声での応答、整理カード（悩み・選択肢・小さな行動）の作成のためだけに使用します。広告や第三者への販売には使用しません。
送信しないもの: 氏名、メールアドレス、アカウントの識別子、引き継ぎコード、端末の情報、購入情報。
保存と保護: Googleには有料のGemini API（有料サービス）として送信します。Googleの利用規約（Gemini API 追加利用規約の有料サービスの節）に基づき、送信した内容はGoogleの製品改善には使用されません。Googleは不正利用の検知と法令対応のため、一定期間、入力と出力を記録する場合があります。OpenAIへは保存機能を無効にして送信し、録音ファイルはアプリにもOpenAIにも保存しません。OpenAIはAPIの利用規約・データ処理に関する条件に基づき、本ポリシーと同等以上の保護のもとでデータを取り扱います。OpenAIによるデータの取扱いは同社のプライバシーポリシー（https://openai.com/policies/privacy-policy/）、Googleによるデータの取扱いはGemini API 追加利用規約（https://ai.google.dev/gemini-api/terms）と同社のプライバシーポリシー（https://policies.google.com/privacy）をご確認ください。

4. その他の外部サービス

購入状態の管理には、iOSではApple（App Store Server API）、AndroidではGoogle PlayおよびRevenueCatを利用します。アカウントと相談記録の保存、およびサービスの運用には、Cloudflare, Inc.（米国）のクラウドサービスを利用します。これらの事業者には各処理に必要な範囲の情報だけが送信されます。

5. 広告

無料利用時に、運営者が管理する自社アプリ等の広告を表示することがあります。広告表示を目的とする第三者への行動追跡や、第三者広告ネットワークへの個人データ送信は行いません。有料プランでは広告を表示しません。広告の在庫は、アプリの種類（iOS/Android）だけを添えて運営者のサーバーから取得し、ログイン前や記録プランの利用中には取得しません。

6. 保存と安全管理

相談記録は利用者のアカウントに紐づけて、運営者が管理するサーバー（Cloudflareのクラウド基盤）に保存します。通信はHTTPSで保護し、認証情報は安全な方法で管理します。法令対応、購入の重複防止、返金処理などに必要な記録は、目的達成に必要な期間保持する場合があります。

7. 削除

相談ノートはアプリ内で個別に削除できます。設定画面の「アカウントと相談データを削除」からアカウントと相談データの削除を依頼できます。詳細はアカウント削除案内をご確認ください。
